# pedit v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Linux desktop editor (CapCut-style UI) where Claude, run via the user's own `claude -p`, edits a timeline as a reviewable draft, with smooth 4K 120fps preview via proxies and full-quality export.

**Architecture:** Electron app. Pure-TypeScript editing core (`src/shared`) holds the timeline model, commands and draft/undo session; the main process owns that session, the media pipeline (bundled ffmpeg), export, an MCP server on 127.0.0.1, and the Claude runner. The renderer is React UI plus a WebCodecs/WebGL preview engine reading proxies; it sends commands over IPC and receives state broadcasts.

**Tech Stack:** Electron, electron-vite, React 18, TypeScript (strict), Zustand, Tailwind + Radix, Mediabunny, WebGL2, Web Audio, `@modelcontextprotocol/sdk`, zod, bundled GPL ffmpeg/ffprobe, Vitest, Playwright (`_electron`), electron-builder.

**Spec:** `docs/superpowers/specs/2026-10-31-pedit-v0.1-design.md` — read it before any task.

**Milestones:** the 15 tasks are grouped into three milestones of five. Each milestone ends with a **checkpoint**: the app runs and the user tries it by hand. Executors stop at each checkpoint and wait for the user's go-ahead before starting the next milestone.

| Milestone | Tasks | What the user can try at the checkpoint |
|---|---|---|
| 1 · Import and watch | 1–5 | Open the app, import 4K 120fps clips, see them appear instantly, watch proxies build, play and scrub any clip smoothly |
| 2 · Edit by hand and export | 6–10 | Build an edit on the timeline (trim, split, move, title, music, undo), play it, export an MP4 |
| 3 · Claude edits | 11–15 | Ask Claude in chat, watch it work, preview/accept/reject the draft, export; install as an AppImage |

## Global Constraints

- Personal use; no license constraints. Code may be borrowed from SynthCut (github.com/relo-video/synthcut), OpenChatCut (github.com/0xsline/OpenChatCut), Remotion, etc. when it saves time.
- Node 24, TypeScript strict, ESM. Linux first; no code path may assume Linux-only (use `path`, `os`, no hardcoded `/`).
- Bundled ffmpeg must have: libx264, libx265, zscale (zimg), h264_nvenc/hevc_nvenc, h264_vaapi, h264_qsv. Dev machine: Intel Raptor Lake iGPU + RTX 4050 Laptop, 16 threads, 22 GB RAM.
- All project mutations (UI, import and Claude) go through `applyCommand` in `src/shared/commands.ts`. Nothing else mutates a `Project`.
- Times are integer milliseconds. IDs are stable opaque strings (`m_`, `c_`, `t_`, `a_` + 6 hex). Nothing addresses items by index.
- Claude is spawned only as: `claude -p <msg> [--resume <sid>] --mcp-config <file> --strict-mcp-config --allowedTools "mcp__pedit__*" --append-system-prompt <guide> --output-format stream-json --verbose`. The app never reads or stores Claude credentials. Binary path overridable with env `PEDIT_CLAUDE_BIN` (used by tests).
- Proxy: H.264 MP4, long edge ≤960px, fps = min(source, 60), GOP = round(proxyFps/2), no B-frames, AAC 128k, `+faststart`. HDR sources tone-mapped with the shared `TONEMAP_VF` in both proxy and export.
- Export: SDR Rec.709 only; aspects 16:9/9:16/1:1; resolution 1080p or 2160p (short edge 1080/2160); fps 30/60/source (≤120).
- Preview targets: 60fps playback, scrub latency <100ms, 10-min timeline of 4K120 sources on the dev machine.
- Commit messages: one line, ≤10 words, plain words, no trailers or attribution.

## Review Focus

1. **Moved/deleted source media** — project still opens, item shows offline, export is refused with a message naming the missing files. (Task 4, Task 10)
2. **Filenames with spaces, unicode and quotes** (`Tōkyō day 1 'final'.mov`) — probe, proxy, thumbnails and export all work. (Task 1 fixture used in Tasks 2, 3, 10)
3. **Phone rotation metadata** (portrait clip stored landscape + rotate 90) — width/height reported rotated, preview and export upright. (Task 2, Task 5, Task 10)
4. **Clips without an audio stream mixed with clips that have one** — preview and export keep A/V sync and total duration. (Task 8, Task 10)
5. **Claude run fails mid-way** (not logged in, usage limit, Stop pressed, process crash) — draft so far stays reviewable, error shown in chat, input re-enabled. (Task 12, Task 13)

# Milestone 2 · Edit by hand and export (Tasks 6–10)

### Task 6: Timeline commands

**Files:**
- Modify: `src/shared/commands.ts`
- Test: `tests/shared/commands.test.ts`

**Interfaces:**
- Consumes: Task 4's `applyCommand`, `CommandError`, `CommandResult`.
- Produces — `Command` union extended with (exact):
```ts
 | { type:'addClip'; mediaId; inMs?; outMs?; after?: ItemId|null; atMs?: number }
 | { type:'removeItem'; id }
 | { type:'moveItem'; id; after?: ItemId|null; toMs?: number }
 | { type:'trimItem'; id; inMs?; outMs? }
 | { type:'splitItem'; id; atMs }
 | { type:'addText'; text; startMs; durationMs; style?: Partial<TextStyle> }
 | { type:'updateText'; id; text?; startMs?; durationMs?; style?: Partial<TextStyle> }
 | { type:'setMusic'; mediaId; inMs?; volume? }
 | { type:'setVolume'; id; volume }
 | { type:'setFormat'; aspect: Aspect }
```
- Semantics (decisions): **video track is ripple** — `startMs` is always recomputed as the sum of preceding durations (`outMs-inMs`); add/remove/trim/move close gaps. `addClip`: `after:null` = first, `after:id` = after that item, `atMs` = nearest boundary, neither = end; defaults `inMs=0`, `outMs=media.durationMs`, volume 1; audio-only media → `invalid`. `moveItem` on video uses `after`; on text/audio uses `toMs`.
